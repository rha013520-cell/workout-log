# 운동 기록

날짜 / 운동 종류 / 횟수 / 시간만 기록하는 심플한 운동 기록 앱입니다.
로그인 없이 브라우저(폰)에만 데이터가 저장되고, 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 깃허브에 올리고 배포하는 방법

1. github.com에서 새 저장소(Repository) 생성
   - Private로 설정하면 코드도 나만 볼 수 있어요 (선택 사항)
   - 이름 예: `workout-log`

2. 이 폴더 안의 파일 전부를 그 저장소에 업로드
   - github.com 저장소 페이지 → "Add file" → "Upload files" → 파일 전부 드래그 앤 드롭 → Commit

3. Settings → Pages 로 이동
   - Source를 "Deploy from a branch"로 설정
   - Branch를 `main`, 폴더는 `/ (root)` 선택 후 Save

4. 몇 분 뒤 `https://[깃허브아이디].github.io/workout-log` 형태의 주소가 생성됨
   (정확한 주소는 Pages 설정 화면 상단에 표시됩니다)

5. 아이폰에서 사파리로 그 주소 접속 → 공유 버튼(□↑) → "홈 화면에 추가"
   → 홈 화면에 아이콘 생성, 이후로는 아이콘 눌러서 바로 실행

## 참고

- 데이터는 각 기기의 브라우저 안에만 저장됩니다. 다른 기기에서 같은 주소를 열면 별도의 빈 기록으로 보입니다.
- 사파리에서 "사이트 데이터 지우기"를 하면 기록이 함께 삭제되니 주의하세요.
